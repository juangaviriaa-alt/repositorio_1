# ¿Que es una etiqueta HTML?

## Una etiqueta en HTML es un elemento que se utiliza para estructurar y definir el contenido de una pagina web como: h1, p, etc.

# ¿Que etiquetas componen la estructura de un archivo HTML?

- HTML: es la principal que compone el archivo
- head: contiene informacion de la configuracion de la pagina
- title: define el titulo que se vera en la pestaña del navegador
- body: en esta esta todo el contenid que puede ver el usuario de la pagina

# Explica 5 etiquetas de texto en HTML

- h1: es una etiqueta la cual configura el tamaño de las letras
- p: es una etiqueta la cual se utiliza para hacer los parrafos que se pueden ver en el body
- b: esta etiqueta pone los textos en negrita
- i: esta etiqueta pone los textos en cursiva
- u: esta etiqueta pone los textos subrayados

# ¿Como funciona un Link en HTML y que etiquetas se usan?

un link sirve para llevar al usuario desde una pagina web hacia otra pagina y archivos. Las etiquetas que se usan son:

- a: esta crea el enlace hacia la pagina
- href: esta indica la direccion del enlace

# css en 3 renglones

Es un lenguaje que se utiliza para darle diseño y apariencia a una página web. ya sea color del texto y fondo, tipo de tamaño de letra, tamaño de elementos, espacios, margenes, diseño de imagenes, bordes, sombras y distribucion de elementos.

# Selectores css

Los selectores en css son las partes de una regla css que indican a que elemento de HTML hacerle los cambios especificados en el css

# ¿Como una etiqueta puede ser modificada por multiples selectores css?

aplicando diferentes reglas a un mismo elemento usando su etiqueta, clase, ID, atributos, etc.

# ¿Que es un componente de React?

Es una parte reutilizable de una pagina o pagina web donde los componentes permiten dividir una interfaz grande en partes pequeñas.

# ¿Como los componentes se relacionan con las etiquetas HTML, diferencias y parecidos?

- relacion: Un componente de React puede contenet etiquetas HTML dentro de su return

- diferencias: Un componente React puede contener logica y codigo javascript. Mientras que HTML principalmente define la estructura.

- parecidos: Los componentes de React se utilizan para crear interfaces. Mientras que las etiquetas HTML se utilizan para crear la estructura de la pagina.

# Tipos de variables en un componente de React

- string: almacena texto
- number: almacena numeros
- boolena: almacena los verdadero o falso
- array: almacena la lista de datos
- object: almacena datos relacionados
- null: almacena la ausencia intencional de valor
- undefined: almacena las variables sin valor definido 

# ¿Que son los props de un componente?

son los componentes que se envian desde un componente padre a un componente hijo

# ¿Que es UseState?

Es un un Hook de React que permite que un componente tenga y controle estado.

# ¿Que es un usEffect?

Es un Hook de React que permite ejecutar código cuando ocurre algo relacionado con el componente.

# diferencias entre UseState y UseEffect

El UseState sirve para gardar y modificar datos y permite que un componente tenga estado. Mientras que el UseEffect Sirve para ejecutar efectos y acciones y permite responder a cambios o eventos del componente.
